Проект первого спринта по автоматизации на Python – задачи по основам Python. 
Проект qa_python_1, каждое задание в отдельном файле (task_1 – task_5). 
Решены задачи: подсчёт общего количества минут из строки временных значений в цикле (методы split(), replace(), оператор in); исправление класса Tester (конструктор, атрибуты, метод work_hard); работа со словарём чемпионов мира по футболу (добавление года, вывод пар «год - страна», проверка наличия значения); работа со списками задач (перенос элемента между списками, удаление, вывод последнего); класс TestCase с конструктором и методами set_step, delete_step, set_result, get_test_case.
